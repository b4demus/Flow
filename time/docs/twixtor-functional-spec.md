Назначение: описать **внешнее поведение** Twixtor Pro (параметры, диапазоны, значения по умолчанию,

## Три плагина в комплекте

1. **Twixtor**: ретайм с автоматическим расчётом векторов движения.
2. **Twixtor Pro**: то же плюс разделение на слои по маттам (до 3 FG + BG), 12 трек-точек,
   направляющие маски AE, вывод векторов.
3. **Twixtor Pro, Vectors In**: ретайм по готовым векторам движения (из 3D или другого плагина).

## Параметры Twixtor Pro (порядок как в UI AE)

Типы: popup = меню, fixed = слайдер с фиксированной точкой, float = float-слайдер, layer = выбор слоя.

### Верх

| Параметр | Тип | Значения | Дефолт |
|---|---|---|---|
| Display | popup | Twixtored Output · Source · FG1 Twixtored · FG2 Twixtored · FG3 Twixtored · Background Twixtored | Twixtored Output |
| Draw Geom | popup | None · All · FG1 · FG2 · FG3 · Main_BG | All |

- **Display = Source** показывает исходник без ретайма. В этом режиме анимируют всё, что задаётся
  во времени исходника: Mark Segments, трек-точки, маски.
- Режимы **FGn/BG Twixtored** показывают один слой после ретайма, чтобы быстро проверить его отдельно.
- **Draw Geom** рисует направляющую геометрию (точки «+» своим цветом, маски цветом из таймлайна),
  но только при Display = Source и только в те кадры, где геометрия реально используется.

### Source Control (группа)

| Параметр | Тип | Значения | Дефолт |
|---|---|---|---|
| 360 Video | checkbox | | off |
| Alt Color Source | layer | | None (= текущий слой) |
| Alt Motion Source | layer | | None |
| Src: Mark Segments | popup | Cut A · Cut B · Cut C · No MV, Use Nearest · No MV, Frame Blend | Cut A |
| Input: Fields | popup | None · Upper Field First · Lower Field First | None |
| Input: Frame Rate | float | 0.1…1000, точность 3 | 29.97 |

Поведение:
- **Alt Motion Source**: по этому слою считается движение, а цвет берётся из Color Source.
  Размеры должны совпадать, иначе выводится полупрозрачный красный кадр (индикатор ошибки).
- **Mark Segments** анимируется во времени исходника. Между кадрами с разными метками Cut A/B/C
  интерполяция не делается: берётся ближайший кадр. Метки «No MV, …» в первом кадре пары
  отключают векторы: отдаётся ближайший кадр или простой бленд.
- **Fields** на входе: каждое поле становится отдельным кадром (30i ведёт себя как 60p).

### Track Control (группа)

| Параметр | Тип | Значения | Дефолт |
|---|---|---|---|
| Motion Vectors | popup | No Motion Vectors · Sloppy · Medium · High · Best | **Best** |
| Image Prep | popup | None · Contrast/Edge Enhance · Delinearize | None |
| Track RGB+A | checkbox | | off |
| Plenty Memory? (Cache Last Motion?) | checkbox | | on |

- Качество векторов задаёт разрешение расчёта: Sloppy = 1/4 и упрощённый метод, Medium = 1/4,
  High = 1/2, Best = полное. В Draft-режиме хоста разрешение ещё делится пополам.
- **Plenty Memory** кэширует последний расчёт векторов (полезно только при замедлении).

### Output Control (группа)

| Параметр | Тип | Значения | Дефолт |
|---|---|---|---|
| Time Remap Mode | popup | Speed · Frame Number | Speed |
| Speed % | fixed | допустимо −10000…10000, слайдер −1000…1000 | 100 |
| Frame Num | float | допустимо −200000…200000, слайдер 0…2000, точность 2 | 0 |
| Frame Interp | popup | Nearest · Blend · Motion Weighted Blend | **Blend** |
| Warping | popup | Inverse · Inverse w/ Smart Blend · Forward · Forward, no Smart Blend | Inverse |
| Motion Blur Compensation | fixed | 0…10 | 0 |
| Output: Fields | popup | None · Upper Field First · Lower Field First | None |
| Output: Frame Rate | float | 0.1…1000, точность 3 | 29.97 |

В некоторых хостах Frame Num регистрируется как fixed-слайдер 0…30000. Output: Frame Rate в AE
фактически берётся из композиции.

Семантика времени (по мануалу):
- **Speed %** масштабирует длительность в секундах, а не число кадров. При разных input/output FPS
  сначала пересчитываются секунды, потом сэмплирование идёт с выходной частотой.
- **Отрицательная скорость** работает как обратный ход «от текущей позиции воспроизведения»,
  а не как переворот клипа. Значит, позиция в исходнике интегрируется по кривой скорости.
- **Frame Num** задаёт прямой номер (возможно дробный) входного кадра. При разных FPS номер
  трактуется в выходной частоте и пересчитывается во входную.
- Как выбирается источник для дробного входного кадра t (между кадрами A и B):
  - No MV + Nearest: ближайший кадр.
  - No MV + Blend: линейный кросс-фейд.
  - MV + Nearest: кадр A сдвигается по полю A→B на (t−A).
  - MV + Blend: A сдвигается вперёд, B назад, результат смешивается по t.
- **Motion Weighted Blend** выравнивает «пульсацию резкости» между исходными и промежуточными кадрами.
- **Smart Blend** правильно обрабатывает пиксели, уходящие за край кадра или приходящие из-за него
  (панорамы, зумы).
- **Forward** (прямой варп) медленнее Inverse, но даёт меньше ghosting, особенно с направляющей
  геометрией и при замедлении больше 3×.
- **Motion Blur Compensation**: при ускорении добавляет моушн-блюр вдоль векторов, при замедлении
  пытается его снять. 0.5 соответствует затвору 180°.

### Main_BG Layer Settings (группа)

| Параметр | Тип | Значения | Дефолт |
|---|---|---|---|
| Main_BG Sensitivity | fixed | 0…100 | 70 |
| First Mask for BG | mask | | None |
| Last Mask for BG | mask | | None |

**Sensitivity** ограничивает допустимую величину смещения: 0 почти запрещает движение (выглядит
как обычный бленд), 100 снимает ограничение. С маттами и трек-точками рекомендуется 100.

### FG1 / FG2 / FG3 Settings (3 одинаковые группы)

| Параметр | Тип | Значения | Дефолт |
|---|---|---|---|
| FGn Matte | layer | | None |
| FGn Matte Chan | popup | Red · Green · Blue · Alpha | Red |
| FGn Motion Sensitivity | fixed | 0…100 | 70 |
| FGn Inv Matte Shrink | fixed | 0…10 px | 0 |
| FGn: First Mask | mask | | None |
| FGn: Last Mask | mask | | None |

Поведение:
- Слои заполняются строго по порядку: FG2 без FG1 игнорируется, FG3 без FG2 тоже. FG1 лежит
  ближе всех к камере.
- Матт FGn рисуется как объект целиком, включая части, закрытые более близкими слоями.
- Каждый слой ретаймится отдельно, BG дорисовывается в местах, закрытых FG, затем всё
  композится обратно.
- **Inv Matte Shrink** сжимает инверсию матта для BG, чтобы края FG не протекали в фон.
- Матт должен совпадать по размеру с исходником, иначе выводится красный кадр-индикатор.
- Цена: примерно +5 кадровых буферов памяти на каждый FG.

### Track Points (группа, 12 точек)

| Параметр | Тип | Значения | Дефолт |
|---|---|---|---|
| Pt n: Use | popup | Don't Use · FG 1 · FG 2 · FG3 · Main_BG Layer | Don't Use |
| Pt n: Pos | point | | (−5%, −5%), то есть за кадром |
| Pt n: Color | color | фиксированная палитра из 12 цветов | |

Точка направляет поток для выбранного слоя, только если Use указывает на этот слой и точка
лежит внутри кадра в **обоих** исходных кадрах пары. Анимируется во времени исходника, удобно
вести трекером AE.

### Скрытые и служебные

- `Hide Mask 1…256`: невидимые параметры (AE 13.2+), вероятно для отслеживания масок слоя.
- `Color` / `Layer` / `Use`: регистрируются только в хосте Combustion, для AE не нужны.
- Регистрация: строка «Registered to: …» или «Unregistered Demo Version» в About. Для нас неважно.

## Twixtor Pro, Vectors In: отличия

Вместо расчёта движения берёт готовые векторы.

| Параметр | Тип | Значения | Дефолт |
|---|---|---|---|
| Vectors: Prev | layer | | None |
| Vectors: Next | layer | | None |
| Vectors: Max Displace | fixed | 0…10000, точность 2 | 2048 |
| Vec Scale X | fixed | −10…10, точность 2 | 1 |
| Vec Scale Y | fixed | −10…10, точность 2 | 1 |

Остальное как у Pro: Display, Mark Segments, Input FPS, Time Remap, Frame Interp, Warping,
MB Comp и FG-матты.

Формат векторов (задокументирован публично, нам он нужен для совместимости):
- R = X (вправо +), G = Y (**вверх +**, противоположно AE).
- Нормировка: v/MaxDisplace в [−1, 1] переводится в [0, 1], затем ×65534 для 16 бит.
  Значит, 32767 означает ноль.
- Prev = поле «текущий → предыдущий», Next = «текущий → следующий». Нужно хотя бы одно, иначе
  красный кадр. Поддерживается только 16 bpc.

## Не установлено (unknowns)

- Точные значения дефолтов некоторых чекбоксов зависят от хоста (видны ветки по коду хоста).
  В таблицах указан вариант для AE.
- Конкретные RGB палитры трек-точек не расшифрованы: несущественно, берём свою.
- Поведение GPU-ветки (OpenCL/OpenGL есть в бинарнике) и режим «360 Video» описаны только
  по названиям. Для 360 предполагается обработка шва equirect-проекции.

## Наш дизайн (решения, не наблюдения)

- **Движок потока**: свой. Варианты: OpenCV DIS (быстро, CPU) или RAFT/RIFE/FILM через ONNX Runtime
  (DirectML/CUDA). Аналоги качества Sloppy…Best = масштаб расчёта и выбор модели.
- **Интерполяция**: bidirectional warp + occlusion-aware blend (свой Smart Blend), forward splatting
  как режим Forward. Для «Best» есть опция нейросетевой интерполяции (RIFE).
- **Совместимость UI**: те же группы, имена и дефолты, чтобы пользователь Twixtor сразу ориентировался.
- **Vectors In и вывод векторов** в том же 16-битном формате: совместимость с пайплайнами RE:Vision.
- **Сравнение по выходу**: одинаковые клипы через Twixtor Pro и через наш плагин при одних
  настройках, метрики PSNR/SSIM/LPIPS по кадрам плюс визуальная проверка ghosting на краях и
  окклюзиях.
