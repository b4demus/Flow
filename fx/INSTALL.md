# Установка Facet

Windows x64, After Effects. В этом наборе 41 AEX.

1. Сохраните проект и закройте After Effects, aerender и другие Adobe-приложения,
   которые используют плагины.
2. Запустите `Facet-Setup-2026-10-21.exe` и нажмите «Установить».
   Либо распакуйте ZIP полностью и запустите `install.cmd`.
3. Подтвердите стандартный запрос Windows на права администратора.
4. После сообщения об успехе запустите AE. Эффекты находятся в меню `Facet ...`.

Setup.exe содержит весь набор; ZIP рядом с ним не нужен. Интернет и Rust для
установки не требуются. Используются штатные Windows PowerShell 5.1 и .NET
Framework 4.8. Сам Setup не подписан сертификатом издателя.

Плагины устанавливаются в общую папку Adobe
`C:\Program Files\Adobe\Common\Plug-ins\7.0\MediaCore\Facet`.
Обновление действует на приложения Adobe, использующие эту общую папку.
CLI `facet.exe` остаётся в `dist` внутри ZIP; установщик не добавляет его в PATH.

Установщик проверяет SHA-256 каждого AEX и CLI, внутренние идентификаторы AEX
и файлы лицензии. Совпадающие версии повторно не копируются. Старые копии
Facet находятся по внутреннему matchName, включая прежние имена файлов,
в MediaCore и стандартных папках Plug-ins установленных AE.
После успешной записи они убираются из папок поиска AE. Чужие плагины,
включая `Flowtime.aex`, не удаляются. Необычные пользовательские папки плагинов
вне этих путей автоматически не сканируются.

Пока Adobe-приложение открыто, запись блокируется. Процессы не завершаются и
проекты не закрываются автоматически. Второй установщик параллельно не запускается.
Установщик не меняет ExecutionPolicy системы и не расширяет права доступа к
папке плагинов. Права администратора нужны для записи в Program Files.

## Резервная копия и откат

Перед заменой файлы сохраняются в
`C:\ProgramData\Facet\Backups\<дата-идентификатор>`.
Точный путь показывается после установки. В этой папке находятся исходные
файлы и `journal.json`; резервные копии лежат вне папок поиска AE.
При ошибке записи установщик автоматически возвращает прежнее состояние.
Если файл был изменён другой программой во время операции, откат остановится
с указанием журнала, чтобы не затереть это изменение.

Для ручного отката распакуйте ZIP, закройте AE и выполните:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -Restore 'C:\ProgramData\Facet\Backups\<дата-идентификатор>'
```

Откат проверяет целостность резервных копий и не перезаписывает файлы,
изменённые после установки. Он возвращает и старые имена/расположение файлов,
поэтому после отката может восстановиться прежняя проблема с дубликатами.

Проверка пакета и плана без изменения установки:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -Check
```

Сборка установщика из готового ZIP: `tools/build_setup.ps1 -PackageZip ... -OutputPath ...`.
Проверка содержимого Setup.exe без установки: `Facet-Setup-2026-10-21.exe /verify <путь-к-json>`.
Эти действия не требуют закрытия AE или повышения прав.

## Состояние эффектов

Это предварительная сборка. PixelSort и PixelMosh ещё дорабатываются,
WarpTransform имеет экспериментальный статус, отдельные возможности
плёночных эффектов и линз пока ограничены. См. `docs/status.md`.

This software is based in part on the work of the Independent JPEG Group.
Лицензия и уведомления устанавливаются вместе с AEX.
